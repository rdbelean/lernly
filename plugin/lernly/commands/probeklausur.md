---
description: Eine neue Probeklausur im echten Klausurformat erstellen und in den Trainer einbauen
argument-hint: "[optional: Schwerpunkt, z. B. schwache Themen]"
---

Erstelle eine neue Probeklausur. Folge dem Skill **lernly-trainer-bauen**, Abschnitt „Probeklausur“.

- Nächster freier Buchstabe als ID (`b`, `c`, …), Datei `_lernly/probeklausuren/<id>.json`.
- Aufbau, Punkte und Dauer wie die echte Klausur, neue Fälle und Zahlen (mit Python gerechnet), keine Wiederholung der vorhandenen Probeklausuren.
- Schwerpunkt: $ARGUMENTS (leer = wie die echte Klausur verteilt; liegt ein Lernstand vor, schwache Themen etwas stärker).
- Prüfen, Trainer neu bauen, in einer Zeile Bescheid geben.
